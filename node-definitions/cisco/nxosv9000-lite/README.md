# NXOSv 9000 Lite Switch
This directory contains the following node definition:

*`nxosv9000-lite.yaml` - Nexus 9000v Lite Switch

### Image Availability

Images for the NXOSv 9000 Lite can be found at <https://software.cisco.com/download/home/286312239/type/282088129/release/10.4%25288%2529>.  Make sure
you download the ones with the -lite in the name.

### Notes

This switch is lighter in features and weight than the base nxosv9000 images.  It only needs one vCPU and 8 GB of RAM.  See
[the deployment page](https://www.cisco.com/c/en/us/td/docs/dcn/nx-os/nexus9000/103x/n9000v-n9300v-9500v/cisco-nexus-9000v-9300v-9500v-guide-release-103x/m-nexus-9300v-and-9500v-lite-nx-os-image.html) for a list of supported features.
